# Apps Script 笔记

Google Apps Script 学习笔记，基于 JavaScript，可直接操作 Google Workspace（Sheets、Docs、Gmail 等）。

## 基础笔记

| 文件 | 内容 |
|------|------|
| `入门.txt` | 环境搭建、基本概念、第一个脚本 |
| `基础知识.txt` | 语法、变量、函数、常用 API |
| `关于时间.txt` | 日期时间处理、定时触发器 |

## 工作实操节选

日常工作中实际用过的脚本片段：

| 文件 | 功能 |
|------|------|
| `BQ刷新状态.js` | 监控 BigQuery 任务刷新状态 |
| `Jira.md` | 通过 Apps Script 调用 Jira API |
| `Slack.md` | 发送 Slack 消息通知 |
| `googleDoc.js` | 操作 Google Doc 文档 |
| `html前端展示.js` | 在 Sheets 侧边栏渲染 HTML 页面 |
| `html对话框.md` | 弹出 HTML 对话框 |
| `html邮件发送.md` | 发送 HTML 格式邮件 |
| `一对多查询.js` | 跨 Sheet 一对多数据查询 |
| `企业微信通知.js` | 推送企业微信 Webhook 通知 |
| `分类汇总多个tab各自内容.js` | 多 Tab 数据分类汇总 |
| `大批量黏贴数据.js` / `大批量黏贴数据2.js` | 高性能批量写入数据 |
| `定位尾行.js` | 定位 Sheet 最后一行 |
| `抽样_完整1.js` | 完整抽样脚本 |
| `筛选替换特定区域.js` | 条件筛选并替换数据 |
| `纯数字转化为逗号分隔.js` | 数字格式转换 |
| `非html对话框.js` | 原生 UI 对话框 |
| `顶部菜单.js` | 自定义 Sheets 顶部菜单 |
