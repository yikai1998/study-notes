只要你的结果最后能数成人数表，比如“买了多少人、没买多少人”，用卡方检验。
只要你的结果是每个人一个具体数字，比如“每人花了多少钱、停留多久”，两组用 t 检验，三组用 ANOVA。


例1 - A 组和 B 组的购买比例是不是不一样？
```py
table = [
    [100, 900],  # A组：买了100人，没买900人
    [130, 870]   # B组：买了130人，没买870人
]

from scipy import stats
chi2, p, dof, expected = stats.chi2_contingency(table, correction=False)
print(p)
if p < 0.05:
    print("B组购买率和A组不一样")
else:
    print("看不出B组和A组购买率有差异")
```
具体结论：
A组购买率 = 100 / 1000 = 10%
B组购买率 = 130 / 1000 = 13%
p = 0.0355  在“没效果”的前提下，这个结果只有 3.55% 的概率出现，挺反常。
因为 p < 0.05，说明 A、B 两组购买率存在显著差异。
又因为 B组购买率 13% > A组购买率 10%，所以可以认为 B 组购买率显著高于 A 组。


例2 - A 组和 B 组的平均停留时长是不是不一样？
```py
A = [30, 35, 33, 31, 29]
B = [41, 39, 45, 42, 40]

from scipy import stats
t, p = stats.ttest_ind(A, B, equal_var=False)
print(p)
if p < 0.05:
    print("B组平均停留时长和A组不一样")
else:
    print("看不出B组和A组平均停留时长有差异")
```
具体结论：
A组平均停留时长大约 31.6 秒
B组平均停留时长大约 41.4 秒
如果 p < 0.05，说明 A、B 两组平均停留时长存在显著差异。
又因为 B组平均 41.4 秒 > A组平均 31.6 秒，所以可以认为 B 组平均停留时长显著高于 A 组。
