GROUP BY 用来把多行按某些列分成若干组，然后对每组做聚合计算。
SELECT 里出现的列，如果不是聚合结果，就必须出现在 GROUP BY 中。
因为聚合后，一组只剩一行；那些非聚合列必须能唯一代表这组。

WHERE 和 HAVING
WHERE 是分组前过滤行。
HAVING 是分组后过滤组。

NULL
GROUP BY 时，NULL 会被当作同一组处理。
也就是说多个 NULL 会归到同一个分组里。

GROUP BY ALL
GROUP BY ALL 会根据 SELECT 里的非聚合项自动推断分组键。
适合少量场景下省略重复书写，但可读性和可控性通常不如显式写列名。

GROUPING SETS
GROUP BY GROUPING SETS 用来一次产生多种分组结果。
可以理解为对不同的 group by 结果做 UNION ALL，但由数据库一次完成。
GROUP BY GROUPING SETS(x,y) is roughly equivalent to GROUP BY x UNION ALL GROUP BY y  
```sql
-- GROUP BY with GROUPING SETS
WITH
  Products AS (
    SELECT 'shirt' AS product_type, 't-shirt' AS product_name, 3 AS product_count UNION ALL
    SELECT 'shirt', 't-shirt', 8 UNION ALL
    SELECT 'shirt', 'polo', 25 UNION ALL
    SELECT 'pants', 'jeans', 6
  )
SELECT product_type, product_name, SUM(product_count) AS product_sum
FROM Products
GROUP BY GROUPING SETS (product_type, product_name)
ORDER BY product_name

/*--------------+--------------+-------------+
 | product_type | product_name | product_sum |
 +--------------+--------------+-------------+
 | shirt        | NULL         | 36          |
 | pants        | NULL         | 6           |
 | NULL         | jeans        | 6           |
 | NULL         | polo         | 25          |
 | NULL         | t-shirt      | 11          |
 +--------------+--------------+-------------*/
```
