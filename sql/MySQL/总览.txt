和 BigQuery 最大区别：
MySQL 没有 QUALIFY
MySQL 没有 UNNEST 风格的数组处理
MySQL 日期函数不同
MySQL 更需要注意索引和性能

命令类型 分析师最常用：
SELECT ...;
CREATE (TEMPORARY) TABLE xxx AS SELECT ...;
DROP (TEMPORARY) TABLE IF EXISTS xxx;
EXPLAIN (FORMAT=JSON) SELECT ...;; 看执行计划 返回的是比较容易读的查询计划

```sql
DROP TEMPORARY TABLE IF EXISTS tmp_customer_spend;

CREATE TEMPORARY TABLE tmp_customer_spend AS
SELECT
  CustomerId,
  SUM(Total) AS total_spend
FROM Invoice
GROUP BY CustomerId;

SELECT *
FROM tmp_customer_spend
WHERE total_spend >= 40;
```

注意点:
1. WHERE 条件最好命中索引
2. JOIN key 最好有索引
3. 大表不要 SELECT *
4. 大表不要随便 ORDER BY RAND()
5. 避免无条件全表扫
6. 聚合前尽量先过滤
7. HAVING 不能用原始列，WHERE 不能用聚合函数
8. MySQL 字符串区分大小写取决于 collation (mysql默认 不区分大小写)

临时强制区分大小写
```sql
WITH t AS (
  SELECT 'Admin' AS a
)
SELECT a, a = 'admin' AS default_check, a COLLATE utf8mb4_bin = 'admin' AS manual_check FROM t

+-------+---------------+--------------+
| a     | default_check | manual_check |
+-------+---------------+--------------+
| Admin |             1 |            0 |
+-------+---------------+--------------+
```


在公司数据库里，尤其生产环境，不要随便执行：
```sql
-- 插入数据
INSERT INTO test_users (user_id, name, created_at)
VALUES (1, 'Alice', NOW());

-- 更新数据
UPDATE test_users
SET name = 'Alice Wang'
WHERE user_id = 1;

-- 删除数据
DELETE FROM test_users
WHERE user_id = 1;

-- 删除表
DROP TABLE IF EXISTS test_users;
```
