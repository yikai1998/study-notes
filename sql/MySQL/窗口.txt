MySQL 没有 QUALIFY，所以要用 CTE

```sql
-- MySQL 替代写法
WITH ranked AS (
  SELECT *,
    ROW_NUMBER() OVER (PARTITION BY CustomerId ORDER BY InvoiceDate DESC) AS rn
  FROM Invoice
)
SELECT * FROM ranked WHERE rn = 1;
```

ROW_NUMBER()  -- 1, 2, 3  不并列，永远连续
RANK()  -- 1, 1, 3  并列，跳过2
DENSE_RANK()  -- 1, 1, 2  并列，不跳号
LAG()  取上一行 e.g. LAG(Total, 1, 0) OVER (...)   -- 上1行，没有则返回 0 而不是 NULL
LEAD()  取下一行

FIRST_VALUE()
LAST_VALUE() ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING  -- ⚠️ 必须加！

LAST_VALUE 有个大坑：
默认窗口框架是到"当前行"为止
如果不加 ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING
每行的 LAST_VALUE 就是它自己，不是真正的最后一个值

SUM() OVER
AVG() OVER
COUNT() OVER

-- ORDER BY 后面默认是
RANGE BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW  -- 意思是：从第一行到当前行

-- 常用的显式写法
ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW      -- 累计到当前行
ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING  -- 整个分区
ROWS BETWEEN 2 PRECEDING AND CURRENT ROW              -- 滚动3行窗口
